# SEO & AEO Image Standards

1. **Mandatory Alt Text**: Every image (cover photos, diagrams, infographics, thumbnails, UI components) must include explicit, descriptive, keyword-rich `alt` text tailored for SEO and AEO (Answer Engine Optimization / Generative Engine Optimization).
2. **MDX Frontmatter**: Every MDX article, guide, or interview must define `coverImageAlt` describing the diagram, architecture, or visual context.
3. **Legal Credits**: Every visual asset must have transparent licensing in `imageCredit` (e.g., CC BY 4.0, Unsplash, Public Domain, Editorial Graphic).
4. **No Empty Alts**: Never use empty or generic alt text like `alt="image"` or `alt="cover"`.
